**Approach/Methodology**



- AI is used for interpretation and personalization only — DB + O*NET holds ground truth, AI advises on top of it

- O*NET as authoritative data source for career/skill taxonomy — not AI-generated

- Manual curation of career list before seeding — AI fills skill details, you control career names

- Single intake/onboarding form drives all modules — one profile, multiple output types

- Regulated career detection via `type` flag — changes prompt and roadmap behavior, not a generic fallback

- Provider-agnostic AI wrapper — one function handles all API calls, swap provider in one line

- Stateless request enriched by DB — form input + DB taxonomy = structured prompt, better output consistency



---



**Resources & Usage**



- **O*NET Web Services API** (`services.onetcenter.org`) — pull occupations, skills, education requirements, growth outlook, salary data into your DB via seed script

- **MySQL** — primary DB, 6 core tables: `users`, `careers`, `skills`, `career_skills`, `roadmaps`, `tasks`, `progress_logs`, `skill_snapshots`, `resources`

- **Claude API / OpenAI API** — wrapped in single `get_ai_response()` function, receives structured prompt built from DB data

- **FastAPI** — existing backend, add route groups per module: `/recommend`, `/roadmap`, `/gap`, `/tasks`, `/progress`

- **React** (if frontend migrated) — needed for dynamic task tracking, progress updates, re-assessment UI



---



**Architecture Decisions**



- Accounts/login are required — app is a returning-user product (task tracking, progress, re-assessment), UUID sessions are not viable for real use

- DB is justified by taxonomy + persistence, not by auth alone — even without accounts, O*NET taxonomy improves output quality

- Career counseling is the onboarding, progress tracking is the retention loop — one-shot tool becomes a product

- Repo name stays `career-counselor-ai` — renaming mid-project breaks references, name still accurate

- O*NET covers ~900 occupations, supplemented by manual Pakistan-specific table — not fully AI-generated, not fully manual
