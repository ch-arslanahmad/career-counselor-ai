# Project Milestones

## Project Milestones

1. **Select project idea, Define problem statement, Identify stakeholders, Identify scope, Feasibility study**

2. **Requirement elicitation**: Define functional and non-functional requirements, SRS Document, Requirement Prioritization

3. **Architectural Design, Model Driven Engineering, Activities**: Define system architecture, Architecture Document, (Flow Chart, ER Diagram, etc.)

4. **Context, Interaction, Structural, Behavioral Models Activities**: Create UML diagrams (Use Case, Sequence, Class, Activity) Model Documentation

5. **Design Patterns, Implementation Planning Activities**: Apply design patterns, Create UI, Design Document

6. **Agile Development Activities**: Develop core modules, prepare: Prototype, Sprint Report

7. **Agile Techniques Activities**: Add advanced features, Updated System, Version Control Records

8. **Testing & Quality Assurance**: Perform unit, integration, system testing, Test Cases: Test Report.

9. **Software Licensing and contract Document** based on the category or domain of the software

10. **Project Management Activities**: Create activity bar and staff allocation chart: Clearly identify all tasks and individually assign to each group member, Present project, Submit Final Report, Slides, submit Source Code
