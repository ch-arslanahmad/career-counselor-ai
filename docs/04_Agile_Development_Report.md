# Agile Development Report

## Sprint 1 Goal
Build a usable career guidance flow with assessment, roadmap generation, and progress tracking.

## Completed Work
- Career assessment form
- Career recommendation rendering
- Roadmap generation
- Skill-gap analysis
- Session progress tracking
- History sync for signed-in users
- Local caching for unsigned users

## Sprint 2 Goal
Improve persistence and clarify how user data is stored and reused.

## Completed Improvements
- Saved assessment history in the database for signed-in users
- Cached unsigned-user history in local storage
- Synced roadmap and skill-gap responses into saved history
- Updated UI copy to explain storage behavior

## Version Control
The project uses conventional commits and a feature-oriented workflow. Non-markdown code and data changes were committed separately from documentation work.
